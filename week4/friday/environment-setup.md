## Notes on reproducibility

- MinIO is run with a mounted volume (`minio-data/`) so the Terraform state
  bucket survives a MinIO container restart between pipeline runs (see
  Challenge E in the project brief).
- The SSH key referenced throughout (`~/.ssh/id_rsa` / `~/.ssh/id_rsa.pub`)
  is expected to already exist on the machine running `pipeline.sh`; it is
  not generated by this pipeline.
- `pipeline.sh` defaults to the Multipass path. Run `./pipeline.sh cloud` to
  use the optional cloud path once the corresponding backend and provider
  blocks are uncommented in `terraform/`.
